# แบบฟอร์มบันทึกข้อความ ขออนุมัติไปราชการ — สำนักงานเกษตรอำเภอสีดา

เว็บฟอร์มขนาดกระดาษ A4 (`595.2pt × 841.92pt`) สำหรับกรอกและสั่งพิมพ์บันทึกข้อความขออนุมัติไปราชการ สำนักงานเกษตรอำเภอสีดา จังหวัดนครราชสีมา พร้อมฟอนต์ `THSarabunIT9` (เลขไทยอัตโนมัติ)

## ใช้งานออนไลน์ (GitHub Pages)
- https://supernopinw.github.io/sida-travel-memo/

## วิธีใช้งาน
1. เปิดหน้าเว็บแล้วแก้ไขข้อความได้ทั้ง **คลิกพิมพ์บนกระดาษ A4 โดยตรง** หรือกรอกผ่าน **แผงช่วยกรอกด้านซ้าย**
2. ระบบจัดเต็มบรรทัดแบบไทย (Thai Distributed) ให้อัตโนมัติสำหรับย่อหน้าเนื้อหา และสลับผู้บังคับบัญชาชั้นต้นให้อัตโนมัติหากผู้ขออนุญาตไม่ใช่เกษตรอำเภอ
3. กดปุ่ม **พิมพ์ / บันทึก PDF (A4)** (หากพิมพ์ผ่านเมนูเบราว์เซอร์ แนะนำให้ตั้งค่า *Margins: None* และปิด *Headers and footers*)
4. สามารถส่งออก/นำเข้าข้อมูลเป็นไฟล์ `.json` และระบบบันทึกแบบร่างลงเบราว์เซอร์ (`localStorage`) อัตโนมัติ
